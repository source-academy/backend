# Python SICP chatbot notes

These files are the professor-provided Python summaries and index terms for
chapters 1–5. Their deployed sources follow these patterns:

- `https://sicp.sourceacademy.org/chatbot_notes_py/sicpy_notes_chapter{chapter}.ex`
- `https://sicp.sourceacademy.org/chatbot_notes_py/sicpy_index_terms_chapter{chapter}.json`

`Cadet.Chatbot.SicpNotesPy` parses them at compile time. After replacing any
source file with a newer deployed version, recompile the application so the
updated summaries are embedded in the module.
